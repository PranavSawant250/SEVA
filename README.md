# SEVA — Personal Life Orchestrator

SEVA is a privacy-first, locally-run personal life orchestrator built with Node.js, Express, SQLite, Ollama (TinyLlama), and React.

## Phase 1 — Foundation Completed
- Complete project folder structure set up
- SQLite database initialized (`backend/seva.db`) with 6 tables:
  1. `emails`
  2. `tasks`
  3. `day_plans`
  4. `chat_history`
  5. `night_summary`
  6. `timetable`
- Express backend running on Port 3001

## How to Run Backend

```bash
cd backend
npm start
```
